# OpenRoad mods 1.2.1 for Euro Truck Simulator 2 1.61

[English](#english) | [Русский](#русский)

## English

Tools and description fixes after an independent review. **The ten mods are unchanged**: the `.scs` files are the 1.2.0 build (package version 1.2.0 inside). If you already have 1.2.0, there is nothing to reinstall.

### What is new in 1.2.1

- **save_money.py `--restore` took the backup of another save.** The game names its saves autosave, autosave_job, autosave_job_3, autosave_drive_5 and so on; `--restore --save autosave` could pick the backup of autosave_job_3. Now only backups of exactly that save are used.
- **The Load screen showed the old money after a write.** The amount is also in `info.sii` of the save (what the Load screen shows). The tools now write it there too.
- `Деньги ETS2.bat` now starts from any folder (it failed in folders with `%` or `^` in the name); two writes within one second no longer fail; the amount may start with the currency sign (`₽10 000`).
- **Free Services:** the description said "all 19 ferry and train crossings are free". The 19 are the crossings of the base game files. Crossings that come with map DLCs (Scandinavia, Beyond the Baltic Sea, Iberia, Greece and others) are in those DLCs and keep their price.

### Files

The same as in 1.2.0: ten `.scs` mods for `Documents\Euro Truck Simulator 2\mod` and `OpenRoad_Workshop_Folders.zip` (ready Steam Workshop folders; only the Free Services description text changed).

## Русский

Исправления инструментов и описания после независимой проверки. **Сами десять модов не менялись**: файлы `.scs` - сборка 1.2.0 (внутри версия пакета 1.2.0). Если 1.2.0 уже стоит, переустанавливать ничего не нужно.

### Что нового в 1.2.1

- **`--restore` в save_money.py брал копию другого сохранения.** Игра называет сохранения autosave, autosave_job, autosave_job_3, autosave_drive_5 и так далее; `--restore --save autosave` мог взять копию autosave_job_3. Теперь берутся только копии именно этого сохранения.
- **Экран загрузки показывал старую сумму после записи.** Сумма лежит ещё и в `info.sii` сохранения (её показывает экран загрузки). Теперь инструменты пишут и туда.
- `Деньги ETS2.bat` запускается из любой папки (в папке со знаком `%` или `^` в имени не находил файл); две записи за одну секунду больше не падают; сумму можно начинать со знака валюты (`₽10 000`).
- **Free Services:** в описании было «все 19 паромов и поездов бесплатны». 19 - это переправы из файлов базовой игры. Переправы, которые приносят DLC-карты (Скандинавия, Балтика, Иберия, Греция и другие), лежат в самих DLC и остаются платными.

### Файлы

Те же, что в 1.2.0: десять модов `.scs` для `Документы\Euro Truck Simulator 2\mod` и `OpenRoad_Workshop_Folders.zip` (готовые папки для Мастерской; поменялся только текст описания Free Services).
